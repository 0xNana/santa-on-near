---
title: API
description: NEAR sponsored-claim endpoint.
---

The active sponsored claim route is `POST /api/near/claim`. It accepts a strict JSON object with gift ID, secret, recipient account ID, issue timestamp, nonce, and NEP-413 signature. The route checks request origin and size, reads the gift from NEAR RPC, verifies the secret commitment and recipient key, and submits the claim through the server-only relayer.

Responses contain fixed error codes and never include raw RPC or signer errors. The request body and private claim key are not logged. Rate limiting is currently in-memory per server process.

`GET /api/near/health` returns 200 when NEAR server settings are configured, the deployed contract responds, its relayer matches the server setting, and the signer is a registered full-access key of the relayer. Configuration, RPC, relayer mismatch, or key authorization failures return 503. Readiness does not prove sufficient balances.
