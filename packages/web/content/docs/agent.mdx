---
title: CLI (legacy)
description: Status of the retained Robinhood/EVM CLI.
---

The original Santa CLI under `packages/agent` targets the retired Robinhood Chain Testnet implementation. It is not connected to the active NEAR Testnet send and claim flows.

Do not use the CLI with mainnet keys or assets. A NEAR-native CLI is not currently provided; use the web app with NEAR Wallet Selector.
